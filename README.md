## Эксперимент DARPA 2000

[Код, данные и результаты эксперимента](DARPA_detection_experiment)

Сравнение Alpha+ и Inductive Miner на журнале DARPA 2000 LLDOS 1.0
при трёх способах формирования трасс: окна 1 минута, окна 5 минут
и сеансы активности узла.

Представлены результаты conformance checking, оценки обнаружения
аномалий и разборы отдельных трасс через сети Петри.

[Открыть интерактивный отчёт в браузере](https://samaralfe.github.io/pm-for-ueba/DARPA_detection_experiment/report.html)
